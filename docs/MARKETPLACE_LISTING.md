# Marketplace listing draft

## Product name

TofiDesk CMS — Multilingual Website, Software & Theme Platform

## Short description

Self-hosted PHP website and operations platform for agencies, creators and businesses in any industry. Includes multilingual public pages, configurable workflows, content management, media gallery, SEO metadata, SMTP queue and optional IMAP inbox collection.

## Feature highlights

- 14 public languages, including Arabic and Persian RTL layouts
- Multilingual first-run installer and 195-country profile matrix
- Configurable forms, appointments, customer-media and staff workflow
- Content, service, blog, gallery and SEO management for any industry
- Open Graph, X Cards, Schema.org, sitemap, canonical and hreflang
- SMTP delivery queue, customer replies and optional TLS IMAP collection
- Generic marketplace ZIP that excludes demo customer data and credentials

## Requirements

PHP 8.2+, PDO SQLite, mbstring, fileinfo, cURL, OpenSSL, GD with WebP support and zlib. The recommended HTTPS document root is `public/`; cPanel/Plesk `httpdocs` root deployment is also supported through the included root `.htaccess` protections.

`README.md`, `KURULUM.txt`, `docs/GO_LIVE.md`, `docs/CODECANYON_RELEASE.md`, `BILGI.md`, `CHANGELOG.md` and `SUPPORT.md`.
