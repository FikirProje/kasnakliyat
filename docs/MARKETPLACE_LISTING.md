# Marketplace listing draft

## Product name

Transport CMS — Multilingual Logistics & Moving Business Website

## Short description

Self-hosted PHP website and operations panel for moving, logistics and transport businesses. Includes multilingual public pages, quote and appointment workflow, content management, media gallery, SEO metadata, SMTP queue and optional IMAP inbox collection.

## Feature highlights

- 14 public languages, including Arabic and Persian RTL layouts
- Multilingual first-run installer and 195-country profile matrix
- Quote, appointment, customer-media and staff workflow
- Content, service, blog, gallery and SEO management
- Open Graph, X Cards, Schema.org, sitemap, canonical and hreflang
- SMTP delivery queue, customer replies and optional TLS IMAP collection
- Generic marketplace ZIP that excludes customer data and credentials

## Requirements

PHP 8.2+, PDO SQLite, mbstring, fileinfo, cURL, OpenSSL, GD with WebP support and zlib. The recommended HTTPS document root is `public/`; cPanel/Plesk `httpdocs` root deployment is also supported through the included root `.htaccess` protections.
