# TofiDesk plugin SDK

TofiDesk plugins extend the sector-neutral runtime without copying or
modifying the core. A plugin is discovered from `plugins/<slug>/plugin.json`;
its manifest is read as data before any release is approved. Manifest discovery
does not execute plugin PHP.

## Create and validate

```bash
php bin/plugin.php scaffold seo-tools "SEO Tools"
php bin/plugin.php validate
```

The shared command remains available for automation:
`php bin/module.php scaffold seo-tools "SEO Tools" plugin`.

The scaffold creates a `plugin` manifest with the current fourteen locale
codes, bounded PHP/platform requirements, empty content and taxonomy
registries, declared hooks, permissions and settings. Add only hooks from the
platform event catalogue. Unknown events, invalid permissions, unsafe slugs,
unsupported field types and incompatible requirements are rejected.

## Manifest boundary

Plugins may declare content types, fields, taxonomies, settings, permissions,
translations and event hooks. They must not replace core tables or execute
code merely because a manifest exists. Public behavior is enabled only after
administrator approval, a signed release, package hash verification and the
product quality gate.

## Marketplace release

Create the plugin as an `addon` product in Product Center, enter all fourteen
localized product/SEO records, upload a signed release with its compatibility
manifest, and approve it through Product quality. A paid entitlement resolves
the add-on release separately from the application and theme releases. Domain
licence, download audit, update expiry, revocation and rollback rules remain
owned by Product Center.

## Safe package rules

- Do not include `.env`, SQLite files, customer media, backups or signing keys.
- Do not place executable PHP in data-only theme payloads.
- Use the release SHA-256 and signature generated by the release process.
- Declare minimum PHP, database and extension requirements accurately.
- Keep migrations additive and reversible; test backup and rollback before
  publishing.
