# Changelog

## 1.1.0

- Added credential-aware SMS and WhatsApp delivery adapters for NetGSM, iletiMerkezi, Twilio and Meta WhatsApp Cloud API.
- Added safe provider test mode, notification queue delivery states and regression coverage.
- Added global administrator session revocation and provider-aware health checks.
- Added configurable request, appointment and verification email subjects.
- Updated Plesk/cPanel environment documentation without shipping live secrets.

- Global transport-business CMS release baseline.
- 14 public locales with RTL support and multilingual installer.
- 195-country safety profile matrix.
- Requests, appointments, CMS, media, gallery, AI review queue, SMTP and optional IMAP collection.
- Marketplace packaging profile with customer-data scan gate.
- Search-engine/social metadata and production deployment documentation.
