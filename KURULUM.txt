TOFIDESK — SUNUCUYA YÜKLEME

1. PHP 8.2 veya üzerini seçin. PDO SQLite, mbstring, fileinfo, cURL,
   OpenSSL, GD/WebP ve zlib eklentilerini etkinleştirin.

2. ZIP'i uygulama klasörüne açın. Alan adının belge kökünü bu klasörün
   içindeki public klasörüne yönlendirin. cPanel/Plesk'te uygulama dosyaları
   httpdocs dışında, yalnız public/ web kökü olacak şekilde yapılandırılabilir.
   storage/ dizini PHP kullanıcısı tarafından yazılabilir olmalıdır.

3. .env.example dosyasını .env olarak kopyalayın ve en az şunları ayarlayın:
   APP_URL=https://example.com
   APP_ENV=production
   Kurulum tokensızdır; ilk yönetici oluşturulduktan sonra /install otomatik kapanır.

4. /install adresini açın. Sunucu kontrollerini tamamlayın, kurulum dilini,
   ülke/işletme bilgilerini ve ilk yönetici parolasını girin. Yönetim paneli:
   /admin/login

5. SMTP, AI, SMS/WhatsApp ve ödeme sağlayıcılarını yalnızca yönetim panelinden
   veya sunucunun özel ortam değişkenlerinden yapılandırın. Gerçek sırları ZIP'e,
   Git'e veya destek mesajlarına yazmayın.
   Lisans merkezi hesap doğrulama/şifre sıfırlama e-postaları için LC_SMTP_HOST,
   LC_SMTP_PORT, LC_SMTP_USER, LC_SMTP_PASSWORD, LC_SMTP_SECURE ve LC_MAIL_FROM
   tanımlayın. SMTP yoksa mesajlar yalnızca özel storage/outbox test kuyruğuna alınır.

   Admin > Legal bölümünde kullanım şartları ve SLA metinlerini 14 dil için
   kontrol edin. Ziyaretçi çerez bildiriminde “Kabul et” seçmeden analytics
   yüklenmez; IMAP_RETENTION_DAYS (0=kapalı, 1–3650 gün) gizlilik politikanıza
   göre ayarlanmalıdır.

6. Worker görevleri için cron:
   php /uygulamanin/tam/yolu/bin/worker.php all
   Yedek için:
   php /uygulamanin/tam/yolu/bin/console.php backup

7. Yayına almadan önce admin girişini, 14 dili, RTL dilleri, SMTP testini,
   şifre sıfırlamayı, hesap doğrulamayı, sitemap/robots, canonical/hreflang,
   cookie consent, lisans aktivasyonunu ve yedek geri yüklemeyi kontrol edin.

PLESK/cPANEL KISA KONTROLÜ
- Alan adı belge kökü public/ (Plesk httpdocs/public) olmalı; uygulama kökü
  ve storage web üzerinden erişilebilir olmamalıdır.
- storage/ yazılabilir, PHP sürümü 8.2+, PDO SQLite/mbstring/fileinfo/cURL/
  OpenSSL/GD-WebP/zlib etkin olmalı.
- Cron: php /tam/yol/bin/worker.php all
- İlk kurulumdan sonra /install kapanır; yönetim: /admin/login.

TEST VE YAYIN ÖNCESİ DOĞRULAMA
- PHP CLI ve web PHP aynı sürüm/eklenti setini kullanmalıdır. Özellikle
  PDO SQLite, SQLite3, GD/WebP, cURL, OpenSSL, mbstring, fileinfo ve zlib
  etkin olmalıdır.
- Depodaki tam smoke testi: python tests/smoke.py
- SMTP loopback testi: python tests/smtp_smoke.py
- Paket bütünlüğü: python tests/release_audit.py ve
  python tests/license_center_smoke.py
- Testler gerçek ödeme, SMS, WhatsApp, AI veya SMTP hesabına bağlanmaz;
  sağlayıcı anahtarı yoksa güvenli test modu kullanılır.
