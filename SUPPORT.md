# Support policy

Technical support covers installation, documented configuration and reproducible defects in the current release on supported PHP versions. It does not include hosting-account administration, third-party API billing, custom design work, legal advice, search-ranking guarantees, data recovery from an unmanaged host or modifications made outside the documented child-theme/custom-CSS workflow.

Before opening a support request, include the product version, PHP version, web-server error excerpt with secrets removed, steps to reproduce and the relevant non-sensitive configuration names. Never send passwords, API keys, database files or customer data in a support ticket.
